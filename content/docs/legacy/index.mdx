This page explains what happened to the `af` command line tool and where each
of its features went. Every old guide under `/guides/` for `af` now redirects
here.

<Callout type="warn" title="af commands do not work in acc">
The current CLI is `acc`. It deploys compute services (containers, templates,
GPU and confidential workloads). The `af sites`, `af storage`, `af functions`,
`af ipns`, `af ens`, `af gateways`, `af agents`, `af observability`, and
`af registry` command groups do not exist in `acc`. If a tutorial tells you to
run one of them, it is out of date.
</Callout>

## Where each feature went

| You used | Now |
|---|---|
| `af sites` (static sites on IPFS, Filecoin, or Arweave) | Not in `acc`. Serve your build output from a container, for example an `nginx` image, with `acc services create --kind docker`. See [Quick start](/guides/quickstart). |
| `af agents` (Eliza and other agents) | Templates. `acc templates list --category AI_ML`, then follow [Deploy an AI agent](/guides/deploy-an-agent). |
| `af functions` | Functions deploy from the web app **Deploy** page. The CLI's `--kind function` is not available yet. |
| `af applications` | Projects and services. See [Manage projects](/guides/projects). |
| `af api-keys` | Personal access tokens: `acc pat create`. See [Create and use access tokens](/guides/api-keys). |
| `af observability` | `acc services logs`, `acc services info`, and `acc deployments`. |
| `af storage`, `af ipns`, `af ens`, `af gateways` | Not available. Container images come from any public OCI registry, for example GitHub Container Registry. |
| `af registry` (self-hosted registry prototype) | Retired. The platform pulls from public registries. |
| `af sites deploy` in CI (GitHub Actions, GitLab, CircleCI, Jenkins) | `acc` with `AF_TOKEN` and `AF_PROJECT_ID` set, and `-y` on commands that confirm. See [Docs for AI agents](/ai-agents). |
| Framework guides (Next.js, React, Astro) and migrations from other static hosts | Build the static output into a container image and deploy it as a service. |

## Custom domains

`af` attached domains to sites. Custom domains for Alternate Clouds services are
not available yet. The old guide is archived at
[Custom domains (archived)](/legacy/custom-domains).
