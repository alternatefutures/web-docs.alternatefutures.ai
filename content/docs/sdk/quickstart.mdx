This page shows the first working calls with the SDK. It assumes you finished
[Install the SDK](/sdk/installation): the three `SDK__*` variables, `AF_TOKEN`,
and `AF_PROJECT_ID` are set.

## Set up

```typescript
import 'dotenv/config';
import {
  AlternateFuturesSdk,
  PersonalAccessTokenService,
  type Project,
} from '@alternatefutures/sdk/node';

const sdk = new AlternateFuturesSdk({
  accessTokenService: new PersonalAccessTokenService({
    personalAccessToken: process.env.AF_TOKEN!,
    projectId: process.env.AF_PROJECT_ID!,
  }),
});
```

## List projects

```typescript
const projects: Project[] = await sdk.projects().list();
for (const project of projects) {
  console.log(project.id, project.name);
}
```

## Create a project

```typescript
const project = await sdk.projects().create({ name: 'my-app-staging' });
console.log('created', project.id);
```

Use the new id as `AF_PROJECT_ID` for a token service scoped to that project.

## List your access tokens

```typescript
const tokens = await sdk.user().listPersonalAccessTokens();
for (const token of tokens) {
  console.log(token.name, token.maskedToken, token.createdAt);
}
```

Tokens are created and revoked with the CLI: `acc pat create --name <name>`,
`acc pat delete <tokenId>`.

## Handle errors

```typescript
try {
  await sdk.projects().list();
} catch (error) {
  if (error instanceof Error && error.name === 'AuthorizationError') {
    console.error('Token rejected or no access to this project');
  } else {
    throw error;
  }
}
```

## Deploy something

Deploying services, reading logs, and choosing templates or regions are not in
the SDK. From the same script, shell out to the CLI; every command runs
without prompts once `AF_TOKEN` and `AF_PROJECT_ID` are set:

```typescript
import { execFileSync } from 'node:child_process';

const out = execFileSync('acc', ['services', 'list'], { encoding: 'utf8' });
console.log(out);
```

Or call the GraphQL API directly at `https://api.alternatefutures.ai/graphql`
with the token as a bearer token. The [command reference](/cli/commands) lists
what the CLI can do; [Docs for AI agents](/ai-agents) covers the
non-interactive contract.
