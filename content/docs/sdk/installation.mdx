This page shows how to install and configure the SDK. What it covers is in the
[SDK overview](/sdk).

## Before you start

- Node.js 18.18.2 or later (`node --version`).
- A personal access token: `acc pat create --name my-app`. Copy it; it is
  shown once. See [Create and use access tokens](/guides/api-keys).
- A project id: `acc projects list`.

## 2. Point it at the current API

The package's built-in endpoint defaults point at hosts that no longer exist,
so set these before constructing anything:

```bash
# .env
SDK__GRAPHQL_API_URL=https://api.alternatefutures.ai/graphql
SDK__IPFS__STORAGE_API_URL=https://api.alternatefutures.ai   # required by the constructor; only the retired storage clients use it
SDK__UPLOAD_PROXY_API_URL=https://api.alternatefutures.ai    # same
AF_TOKEN=...          # your personal access token
AF_PROJECT_ID=...     # from acc projects list
```

Add `.env` to `.gitignore`. The two storage variables must be present or the
constructor throws `EnvNotSetError`, even though nothing that works today
reads them.

## 3. Construct the SDK

Use the `/node` entry point on a server and the default entry point in a
browser. The token service takes the token and the project.

```typescript
import 'dotenv/config';
import { AlternateFuturesSdk, PersonalAccessTokenService } from '@alternatefutures/sdk/node';

const sdk = new AlternateFuturesSdk({
  accessTokenService: new PersonalAccessTokenService({
    personalAccessToken: process.env.AF_TOKEN!,
    projectId: process.env.AF_PROJECT_ID!,
  }),
});
```

Prefer options over environment variables? Pass `graphqlServiceApiUrl` to
both constructors:

```typescript
const graphqlServiceApiUrl = 'https://api.alternatefutures.ai/graphql';

const sdk = new AlternateFuturesSdk({
  graphqlServiceApiUrl,
  ipfsStorageApiUrl: 'https://api.alternatefutures.ai',
  uploadProxyApiUrl: 'https://api.alternatefutures.ai',
  accessTokenService: new PersonalAccessTokenService({
    personalAccessToken: process.env.AF_TOKEN!,
    projectId: process.env.AF_PROJECT_ID!,
    graphqlServiceApiUrl,
  }),
});
```

## 4. Verify

```typescript
const projects = await sdk.projects().list();
console.log(projects.map((p) => p.name));
```

A list of your project names means the token, the project, and the endpoint
are all right.

## Troubleshooting

- **`EnvNotSetError: SDK__IPFS__STORAGE_API_URL`** (or `SDK__UPLOAD_PROXY_API_URL`).
  The constructor requires both. Set them as in step 2.
- **`fetch failed`, TLS handshake errors, or a hostname ending in
  `service.alternatefutures.ai`.** The SDK is using its retired default
  endpoint. Set `SDK__GRAPHQL_API_URL` (or `graphqlServiceApiUrl` on both
  constructors).
- **`AuthorizationError`.** The token is wrong, revoked, or does not have
  access to `AF_PROJECT_ID`. Check with `acc pat list` and `acc projects list`.
- **`SdkRequiredNodeRuntimeError`.** A legacy Node-only client was called from
  the browser build. Those clients are retired; see the [overview](/sdk).
