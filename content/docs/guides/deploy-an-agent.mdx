---
title: "Deploy an AI agent"
description: "Tutorial: deploy the Alternate Agent template with a monthly budget cap, give it a name and instructions, chat with it at its URL, and shut it down."
---

This tutorial takes you from a signed-in CLI to a running AI agent with a
chat UI, a spending limit, and a clean shutdown. It takes about ten minutes.
You will use the **Alternate Agent** template, which bills its model usage to
your Alternate Clouds credits, so no third-party AI keys are needed.

## Before you start

- You have finished the [Quick start](/guides/quickstart): `acc` is installed,
  you are logged in, and a project is active (`acc whoami` shows it).
- Your organization has credits or an active trial.

## 1. Look at the template

```bash
acc templates info alternate-agent
```

The output lists the resources (1 vCPU, 2 GiB memory, 2 GiB storage), the
port, and the environment variables. Two are required:

| Variable | What to put in it |
|---|---|
| `AF_API_KEY` | A personal access token. The agent uses it to pay for chat, image, and video inference from your credits. |
| `AF_ORG_ID` | Your organization id, the segment after `/org/` in the web app's address bar (`clouds.alternatefutures.ai/org/<this part>/...`). |

Everything else has a default. You will set `AGENT_NAME` and
`AGENT_INSTRUCTIONS` to make it yours.

## 2. Create a token for the agent

```bash
acc pat create --name my-agent
```

Copy the token; it is shown once. Giving the agent its own token means you can
revoke it later with `acc pat delete` without touching anything else.

## 3. Deploy with a budget cap

Replace the two values in angle brackets with the token from step 2 and your
organization id from step 1.

```bash
acc services create --kind template --template alternate-agent \
  --name my-agent \
  --env AF_API_KEY=<token-from-step-2> \
  --env AF_ORG_ID=<your-org-id> \
  --env AGENT_NAME="Atlas" \
  --env AGENT_INSTRUCTIONS="You are a concise assistant for the Atlas project." \
  --budget-monthly 20 \
  -y
```

What the flags do:

- `--budget-monthly 20` stops the service once it has spent 20 dollars in a
  month. The platform enforces it, not your machine.
- `-y` accepts the defaults for everything you did not pass (region "Any",
  the template's resources, no GPU) instead of prompting.

The command prints the new service id. The deployment now goes through
placement and start; [How a deployment works](/guides/how-deployments-work)
explains each stage.

## 4. Watch it come up

```bash
acc services list
```

Run it again every twenty seconds or so until the service shows as active with
a URL of the form `https://my-agent-app.alternatefutures.ai`. If it is still
waiting after a few minutes, see
[The deployment stays in a waiting or creating state](/troubleshooting#the-deployment-stays-in-a-waiting-or-creating-state).

To see the agent starting:

```bash
acc services logs <serviceId> --tail 100
```

## 5. Talk to it

Open the URL from step 4 in a browser. The chat UI loads with the name you
set. Ask it something; the reply is billed to your credits through the token
from step 2, and you can see the charge later under **Billing**, **Usage** in
the web app.

## 6. Change it without redeploying by hand

Environment variables live on the service. To give the agent a different
personality:

```bash
acc services env set <serviceId> AGENT_INSTRUCTIONS "You answer only with haiku."
acc services deploy <serviceId>
```

The redeploy creates a new deployment; the URL does not change.

## 7. Shut it down

```bash
acc services close <serviceId>   # stops the service and its charges
acc pat delete <tokenId>         # optional: revoke the agent's token (id from acc pat list)
```

`acc services close` keeps the service definition so you can deploy it again
later. `acc services delete <serviceId>` removes it entirely.

## What you learned

- Templates carry their own resources and declare the variables they need.
- A per-service budget cap is set at deploy time and enforced server-side.
- Configuration changes are environment variables plus a redeploy.
- Closing a service is how you stop paying for it.
